About this project

Method

Each submission is preprocessed (script normalisation, Romanised detection, code-mix ratio) and routed to a language bucket (en / hi / te / code-mixed). Two heads score it: a stylometric head (Head A) and a perplexity-curvature head (Head B, Fast-DetectGPT over mGPT). An optional MuRIL semantic head (Head C) is used only when enough VRAM is available. An interpretable fusion model combines the head scores; the fused probability is temperature-scaled and passed through a per-language split-conformal threshold and an abstention gate that returns human / abstain / machine with a distribution-free bound on the false-positive rate in every language.

Disclaimer

This system produces decision support, never an automatic accusation. An abstain outcome means the evidence is insufficient and the case should go to a human reviewer. No output should be treated as proof of academic misconduct.
